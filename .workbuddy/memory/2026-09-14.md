# 2026-09-14

## 封面锻造厂 Cover Forge · SEO 完善 + Cloudflare Pages 部署准备

**项目性质**：Vite 6 + React 18 + Tailwind v4 单页工具站（Logo → 多平台封面生成器），纯客户端渲染、无路由。

### 背景
- 原 `index.html` 仅有 charset / viewport / title 三个标签，SEO 基本空白。
- 本地 git 仓库已 init（branch `main`），但**无任何 commit、无 remote**。
- 目标：完善 SEO 并准备通过 GitHub → Cloudflare Pages 部署。

### 已完成的工作

**1. 重写 `index.html`（head 全量 SEO + 静态内容区）**
- 基础：title（含核心词）、description、keywords、canonical、robots（含 max-image-preview:large）、hreflang（zh-CN / x-default）、author。
- 社交：完整 Open Graph（含 og:image 1200×630 + width/height/alt）、Twitter summary_large_image。
- 图标/PWA：icon-192/512、apple-touch-icon 180、mask-icon、site.webmanifest、theme-color。
- JSON-LD（单 `@graph`，已用脚本校验合法）：
  `WebSite` + `Organization`(sameAs GitHub) + `WebApplication`/`SoftwareApplication`（applicationCategory: DesignApplication，offers 0 CNY）+ `HowTo`(4 步) + `FAQPage`(6 条)。
  FAQ / HowTo 文案与页面可见内容**逐条一致**（避免结构化数据与内容不符）。
- **静态 SEO 内容区** `section.seo-page`（放在 `#root` **之后**）：不依赖 JS，H1×1 / H2×7 / H3×10，中文正文约 1200 字，含平台尺寸表（10 个预设尺寸）、三步流程、FAQ（details/summary）、适用人群、关键词标签云。
  - 关键技术决策：样式写在 index.html 的**内联 `<style>`** 中，因为 `src/index.css` 是要靠 JS 加载的，非 JS 爬虫拿不到。
  - 放在 `#root` 之后而非之前：React 只接管 `#root`，静态区不会被覆盖，无需在 main.jsx 里做移除逻辑。
- `<noscript>` 提示块（保留可读内容）。

**2. 新增 `public/` 下部署与爬虫文件**
- `robots.txt`：Allow all + Baiduspider/Googlebot/Bingbot/Sogou/360Spider/YisouSpider + AI 爬虫（GPTBot/OAI-SearchBot/ClaudeBot/PerplexityBot）+ Sitemap 指向。
- `sitemap.xml`：含 image:image 扩展与 hreflang 备选链接。
- `site.webmanifest`：PWA manifest（含 maskable icon）。
- `_headers`：Cloudflare Pages 安全响应头（nosniff / X-Frame-Options / Referrer-Policy / Permissions-Policy / HSTS）+ 分级缓存策略。
- `_redirects`：`/* /index.html 200` SPA 回退（静态资源优先匹配）。

**3. 生成的图片资源**（`scripts/gen-assets.py`，Pillow）
- `public/og-cover.png` 1200×630（由 `docs/screenshot-editorial.png` 居中裁剪按 1.905:1 缩放）
- `icon-512.png` / `icon-192.png` / `apple-touch-icon.png`（logo.png 补透明边成正方形再缩放）

**4. 工程配置**
- `.gitignore`（忽略 node_modules / dist / .wrangler / .env / 临时文件）
- `.nvmrc` = `20`（Vite 6 要求 Node ≥18，Cloudflare Pages 会读取）
- `package.json` 增加 `"set-domain": "node scripts/set-domain.mjs"`
- `scripts/set-domain.mjs`：一键把 index.html / robots.txt / sitemap.xml 里的旧域名替换为新域名；旧域名自动从 canonical 读取，因此可重复执行。
