# 文章目录（posts/）使用说明

这个文件夹就是**博客的全部内容源**。往这里放一个 `.md` 文件，网站构建时就会
自动生成一个 `/blog/<slug>/` 的静态页面，无需改任何代码。

## 每日更新工作流（Obsidian 同步）

1. 在 Obsidian 里「打开文件夹作为库」，选择本目录 `D:\origin\xianyu_fengmian\posts`
2. 安装社区插件 **Obsidian Git**（设置 → 第三方插件 → 关闭安全模式 → 浏览社区插件）
3. 插件设置里把 **Auto commit-and-sync interval** 设为 10（分钟），
   或手动用命令面板 `Obsidian Git: Commit-and-sync`
   （本机 GitHub 走 SSH 已配置好，插件直接用系统 git，无需额外登录）
4. 写文章 → 保存 → 插件自动 commit & push → Cloudflare Pages 检测到推送，
   1~2 分钟后文章自动上线

> 插件会提交整个仓库的改动，所以平时写完工具代码记得随手提交，保持仓库干净。

## 文章格式（复制 `_template.md` 改名即可）

```yaml
---
title: 文章标题（15-30 字，含一个搜索关键词）
description: 150 字以内的摘要（会用作 meta description）
date: 2026-09-15
tags: [自媒体, 封面设计]
keywords: 关键词1,关键词2
slug: english-slug
draft: false        # true 则不会发布
---
```

- **文件名建议**：`YYYY-MM-DD-english-slug.md`，slug 用英文小写 + 连字符
- **slug** 决定文章地址 `/blog/<slug>/`，发布后不要改（改了等于换地址，旧链接失效）
- 正文从 `##` 小节开始写，不要再写 `#` 一级标题
